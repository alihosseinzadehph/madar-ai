# مَدار — سایت آموزش و خدمات ایجنت

سایت فارسی مَدار، با هویت فیزیک سیستم‌های پیچیده، معرفی دورهٔ شش‌جلسه‌ای، دو نمونهٔ محصول، اعضا و فرم آشنایی.

- پیش‌نمایش محلی: `npm start`
- بررسی سینتکس: `npm run check`
- [راهنمای بارگذاری روی GitHub](UPDATE-GITHUB-FA.md)
- [فعال‌سازی دریافت فرم](CONTACT-SETUP.md)
- [معرفی سایت به گوگل و ثبت نقشهٔ سایت](SEO-SETUP-FA.md)
- [پوستر قابل ویرایش](assets/course/poster.html)

فرم با FormSubmit کار می‌کند و پیش از دریافت عملی درخواست‌ها باید ایمیل مقصد تأیید شود. `contactActivated` فقط پس از تأیید و دریافت آزمایش واقعی روشن می‌شود. رمز، کلید خصوصی یا توکن دسترسی در این مخزن قرار ندهید.

`CNAME` و `.nojekyll` تنظیمات GitHub Pages هستند. مسیر اصلی انتشار `main` و ریشهٔ مخزن است.
